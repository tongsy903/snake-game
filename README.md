# 🐍 贪吃蛇 Snake

一个用 **Python 标准库**（`tkinter` + `winsound`）实现的贪吃蛇游戏。
**零第三方依赖**，Windows / macOS / Linux 均可运行（音效仅在 Windows 生效，其余平台自动静音）。

## 运行

```bash
python snake.py
```

## 操作

| 按键 | 功能 |
| --- | --- |
| 空格 / 方向键 / WASD | 从开始画面开局（方向键开局即朝该方向） |
| 方向键 / WASD | 移动转向 |
| 空格 | 暂停 / 继续（游戏结束后重开） |
| R | 重新开始 |
| H | 排行榜 TOP10（本地持久保存 `snake_highscores.json`） |
| M | 开关音效 |
| Esc | 退出 |

## 玩法与特性

- 每吃满 6 个食物升一关：加速、逐步出现紫色障碍墙
- 食物用 BFS 可达性检测生成，保证永远能被吃到
- 排行前 10 名记录昵称/分数/关卡/日期
- 音效全部运行时合成（正弦波→16bit WAV），无需音频素材
- 60fps 平滑滑动动画、棋盘格背景、胶囊渐变蛇身（带眼睛）、高光苹果

## 从提交历史学习这个项目是怎么长出来的

这个仓库的 `main` 分支按真实开发顺序保留了 6 个里程碑，
`git log` / GitHub 上的 commit 列表就是一堂完整的"游戏开发 + Git"课：

| 提交 | 里程碑 | 你能学到 |
| --- | --- | --- |
| v1 | 基础可玩版 | tkinter 画布、游戏主循环（`after` 定时）、碰撞判定、方向队列 |
| v2 | 商用完善 | MIT 许可、BFS 寻路保底、JSON 持久化排行榜、WAV 合成原理 |
| v3 | 修复"没声音" | **读官方文档定位 bug**：`winsound` 不允许内存+异步组合，改用临时文件异步播放 |
| v4 | 开局画面 + 键盘焦点 | GUI 事件焦点模型、状态机（就绪/进行/暂停/结束）、回调去重 |
| v5 | 画面圆润化 | Canvas 分层标签、插值动画、圆角绘制、调色板设计 |
| docs | 文档与许可证 | README/LICENSE/.gitignore 等工程化习惯 |

每个 commit 说明都写清了"当时用户反馈了什么 → 根因 → 怎么改"。
配合 `git show <提交号>` 或 PyCharm 的 **Git → Log** 逐个查看 diff，效果最佳。

## 推荐自学路径（配合本仓库）

```bash
# 看某个里程碑改了哪些行
git show 5d8f3f0

# 相邻版本对比（例如 v4→v5 的重绘）
git diff bca054e 5d8f3f0

# 在 PyCharm：底部 Git 面板 → Log → 点任意提交看 diff
```

自己动手练：把 `snake.py` 复制一份，尝试——
加"速度随长度平滑变化"、改主题色、给排行榜加删除按钮、把游戏移植成 `pygame` 版本。

## 代码结构速览

- 配置与颜色常量 → 文件头
- 纯函数（排行榜读写、BFS、障碍生成、WAV 合成）→ 便于单独测试
- `SoundManager`：音效合成 + 临时文件异步播放
- `SnakeGame`：状态管理 → 输入 → 主循环 → 绘制，自上而下阅读
